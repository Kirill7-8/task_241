## 1. Какой по умолчанию используется порт для подключения?
По умолчанию SSH использует порт 22
## 2. Можно ли его изменить? если да то как?
Да, чтобы изменить порт SSH, нужно отредактировать файл `/etc/ssh/sshd_config`, найти и изменить строку `Port 22` на новый номер.
## 3. Какая служба отвечает за обработку запросов на подключения по ssh?
За обработку подключений отвечает служба `sshd` (SSH Daemon)
## 4. Какой файл конфигурации отвечает за его настройку?
Файл конфигурации SSH-сервера — `/etc/ssh/sshd_config` обычно, но в альтах `/etc/openssh/sshd_config`

## 11. Что хранится в файле known_hosts?
Файл `~/.ssh/known_hosts` хранит **отпечатки ключей** (fingerprints) SSH-серверов, к которым подключался пользователь. Это защищает от атак "человек посередине" - система проверяет, что ключ сервера не изменился.
