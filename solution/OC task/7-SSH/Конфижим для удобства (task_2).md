## 1. Где хранятся пользовательские и системные настройки подключения?
Есть два уровня настроек SSH‑клиента - cистемные и пользовательские:
- Системные для всех пользователей `/etc/ssh/ssh_config`
- Пользовательские только для текущего юзера `~/.ssh/config` файл в домашней папке пользователя.
## 2. Что за файл options?
Это конфигурационный файл SSH-клиента, где можно задавать индивидуальные параметры подключения для разных хостов, чтобы не вводить их каждый раз вручную.
## 3-4. Отредактируйте файл options так, чтобы можно было подключаться не вводя имя пользователя и порт. Назовите удобным для вас способом
открываем
```bash
nano ~/.ssh/config
```
Прописываем по схеме:
```bash
Host <Название сервера>
	HostName <Имя хоста>
	User <Юзернейм>
	Port <Порт для подключения>
```
