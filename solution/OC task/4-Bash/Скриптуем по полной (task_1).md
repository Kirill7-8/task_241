## 1. Что такое шебанг?
Шебанг (shebang, #!) — это специальная строка в начале скрипта в Unix-подобных операционных системах, которая указывает системе, какой именно интерпретатор (например, bash, Python) должен использоваться для выполнения этого скрипта, что позволяет запускать его как самостоятельную программу без явного вызова интерпретатора. Он начинается с символов `#` (хеш) и `!` (восклицательный знак) и содержит путь к исполняемой программе-интерпретатору.
## 2. Обязательно ли исполняемый файл должен иметь соответствующее расширение?
Нет, исполняемому файлу в Linux не обязательно иметь конкретное расширение (например, `.sh`). Главное — чтобы файл имел право на выполнение (`chmod +x`) и корректный шебанг или был бинарным исполняемым файлом. Расширение служит только для удобства понимания человеком
## 3. Напишите скрипт который выполнит автоматически действия из блока работы с файлами. ( не забудьте включить set -euo pipefail для того что бы ваш скрипт было удобнее отлаживать. Опишите что включают эти флаги)
```bash
set -euo pipefail
```

Описание флагов set:
- e: Прервать выполнение скрипта при любой ошибке (ненулевом коде возврата команды).
- u: Прервать выполнение, если встретится неопределённая переменная.
- o pipefail: Учитывать ошибки в конвейерах (pipes). Без этого флага ошибка в середине конвейера игнорируется.
```bash
#!/bin/bash
set -euo pipefail
echo "Начало"

echo "Переместиться между директориями"
mkdir -p test
cd test

echo "Вывести список файлов в директории"
ls

echo "Вывести список Всех файлов в директории"
ls -R

echo "Создать папку с подпапками"
mkdir -p folder1/testfolder1/testfolder2
echo "Содержимое теперь"
ls -R

echo "Внутри папки создать файлик и записать в него что-нибудь"
cat > folder1/testfolder1/testfolder2/info.txt << EOF
что-нибудь
EOF
cat folder1/testfolder1/testfolder2//info.txt


echo "Переместить файл из одной директории в другую"
mkdir -p folder2
mv folder1/testfolder1/testfolder2/info.txt folder2/
echo "Файл перемещён в folder2:"
ls folder2


echo "Скопировать файл из одной директории в другую"
cp folder2/info.txt folder1/
echo "Файл скопирован обратно в folder1:"
ls folder1


echo "Переименовать файл"
mv folder1/info.txt folder1/renamed.txt
ls folder1

echo "Сравнить содержимое файла"
echo "Добавим изменение в один файл"
echo "гойда" >> folder2/info.txt
diff folder1/renamed.txt folder2/info.txt || true


echo "Отсортировать содержимое файла по возрастанию и убыванию"
echo "По возрастанию:"
sort folder2/info.txt

echo "По убыванию:"
sort -r folder2/info.txt


echo "Удалить все папки и файлы"
cd ..
rm -rf test
echo "Все созданные папки и файлы удалены."

```
