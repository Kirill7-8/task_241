## 1. Запретите пользователю user1 из предыдущего задания выполнять вход в систему

```bash
sudo usermod -L user1
```

## 2. Как вы это сделали?
заблокировали пароль
## 3. Какие ещё способы это сделать вы знаете?
```bash
sudo usermod -s /usr/sbin/nologin user1 # изменили оболочку на /sbin/nologin
sudo passwd -l user1 # аналогично способу из певрого пункта
sudo usermod -e S user1 # можно установить срок истечения пароля, где S - количество секунд пройденных с 1 янв. 1970
```
