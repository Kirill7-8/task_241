
## 1. Переместиться между директориями
Для перемещения между директориями, как правило, используют команду cd
1. Перейти в абсолютный путь
	cd /путь/к/директории      
	![Переход из корневого каталога в домашний каталог пользователя](скриншотики/Pasted%20image%2020251222165253.png)
	Переход из корневого каталога в домашний каталог пользователя
2. Перейти в поддиректорию
	cd папка_внутри_текущей
	![переход в папку 'Загрузки'](скриншотики/Pasted%20image%2020251222165809.png)
	переход в папку "Загрузки" 
3. Подняться на уровень выше    
	cd ..
	![переход обратно в родительскую директорию](скриншотики/Pasted%20image%2020251222165923.png)
	переход обратно в родительскую директорию
4. Перейти в домашнюю директорию
	cd ~                  
	![переход в домашнюю директорию](скриншотики/Pasted%20image%2020251222170054.png)
	переход в домашнюю директорию (ну, мы в ней и были)
5. перейти в корневую директорию
	cd /      
    ![переход в корневую директорию](скриншотики/Pasted%20image%2020251222170147.png)

## 2. Вывести список файлов в директории
```bash  
ls                         # только имена
ls -l                      # подробный список
ls -la                     # все файлы, включая скрытые
ls /путь/к/директории      # список в указанной директории            
```

## 3. Вывести список Всех файлов в директории
```bash

## 9. сравнить содержимое файла
```bash
diff файл1.txt файл2.txt
cmp файл1.txt файл2.txt            # бинарное сравнение
```
![Пример diff](скриншотики/Pasted%20image%2020251222174008.png)

## 10. отсортировать содержимое файла по возрастанию и убыванию
```bash
sort файл.txt                      # по возрастанию
sort -r файл.txt                   # по убыванию
sort -n файл.txt                   # числовая сортировка
```
![Пример sort](скриншотики/Pasted%20image%2020251222174443.png)
![Пример sort -r](скриншотики/Pasted%20image%2020251222174601.png)

## 11. удалить все папки и файлы
```bash
rm файл.txt                         # удалить файл
rm -r папка/                        # удалить папку рекурсивно
rm -rf папка/                       # принудительно без подтверждения 
```
![Пример удаления файлов](скриншотики/Pasted%20image%2020251222174832.png)
```
