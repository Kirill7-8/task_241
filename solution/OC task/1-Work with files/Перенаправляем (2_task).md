## 1. Как работают команды >,>>?
**`>`** — перенаправление с перезаписью

```bash

echo "Текст" > файл.txt    # Создаст или перезапишет файл
```

**`>>`** — перенаправление с добавлением в конец 

```bash
echo "Новый текст" >> файл.txt   # Добавит в конец файла
```

## 2. Что такое перенаправление ввода? stderr,stdout;
Ввод и вывод распределяется между тремя стандартными потоками:
- stdin — стандартный ввод (клавиатура),
- stdout — стандартный вывод (экран),
- stderr — стандартная ошибка (вывод ошибок на экран).
Потоки также пронумерованы:
- stdin — 0,
- stdout — 1,
- stderr — 2.
```bash
команда > файл          # stdout в файл
команда 2> файл         # stderr в файл
команда &> файл         # stdout и stderr в файл
команда >> файл         # stdout в конец файла
```

## 5. Перенаправить stdout в stderr и обратно на примере команды kinit, ping, tracert

ping -c 2 несуществующий сайт 2> ошибки_ping.txt # направляем поток ошибок stderr в файл

## 6. Чем отличаются stdout и stderr
`stdout` предназначен для **нормальных результатов работы**, а `stderr` — для **сообщений об ошибках или отладочных сообщений**, что позволяет разделять их при перенаправлении, например, сохранять вывод в файл, но ошибки видеть на экране
## 7. Что такое stdin?
stdin(Standard Input) - это стандартный поток ввода, который представляет собой канал для получения данных программой, по умолчанию ассоциированный с клавиатурой, но способный принимать данные из файлов или других процессов через механизмы перенаправления в командной оболочке
## 8. Как отправить весь вывод команды в пустоту?
```bash
команда > /dev/null 2>&1   # весь вывод (stdout+stderr) в никуда
```
