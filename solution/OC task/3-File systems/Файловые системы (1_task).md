## Как можно классифицировать файловые системы? в чём отличия??
не существует идеальной файловой системы, так что каждая подходит для своего случая.
Классифицировать можно по назначению: 
- для дисков (ext4, NTFS)
- сетевые (NFS, CIFS)
- специальные (procfs, sysfs). 
По структуре журналирования: 
- журналируемые (ext3, ext4, NTFS) 
- без журнала (ext2, FAT32). 
По поддержке метаданных: 
- с расширенными атрибутами (ext4, XFS)
- без (FAT32). 
По области применения: 
- универсальные (ext4)
- для флеш-накопителей (F2FS)
- для оптических дисков (UDF).

Отличия заключаются в надёжности, производительности, поддержке прав доступа, максимальном размере файла и раздела, а также в совместимости с разными операционными системами.

## Какие файловые системы используются в linux?
ext4 (стандартная для многих дистрибутивов)  
XFS (часто для больших файлов и разделов)  
Btrfs (с поддержкой снапшотов, сжатия и RAID)  
tmpfs (для временных файлов в оперативной памяти)  
procfs и sysfs (виртуальные, для информации о системе и устройствах)  
NFS и CIFS/SMB (сетевые файловые системы)

## Как можно подключить диск в систему, что такое монтирование?
Монтирование - это процесс подключения файловой системы, находящейся на разделе диска, к определённой директории (точке монтирования) в дереве каталогов Linux, чтобы получить доступ к данным.
```bash
mount <т. монтирования> <файловая система> # монтируем файловую систему к дереву каталогов
```

## файловая система procfs, cifs, tpmfs,sysfs. В чём особенности каждой из них? Вывести каталоги к которым примонтированы эти файловые системы
- procfs: виртуальная файловая система, предоставляет информацию о процессах и параметрах ядра в реальном времени. Особенность — её файлы генерируются на лету.  
- cifs (Common Internet File System): сетевая файловая система для доступа к общим ресурсам по протоколу SMB (используется в Windows и Samba).  
- tmpfs: файловая система, размещаемая в оперативной памяти (RAM). Используется для временных файлов. Содержимое теряется при перезагрузке.  
- sysfs: виртуальная файловая система, представляющая иерархическую структуру устройств и драйверов ядра
