## 1. Raid массивы, что такое и какие бывают
RAID (Redundant Array of Independent Disks) — массив независимых дисков, объединённых для повышения надёжности и/или производительности. Основные типы:
- RAID 0 (stripe): Разделение данных между дисками. Повышает производительность, но не обеспечивает отказоустойчивости. Минимально 2 диска.    
- RAID 1 (mirror): Зеркалирование данных на несколько дисков. Обеспечивает отказоустойчивость, но не повышает производительность записи. Минимально 2 диска.
- RAID 5: Чередование с контролем чётности. Сочетание производительности и отказоустойчивости. Минимально 3 диска.
- RAID 6: Как RAID 5, но с двойным контролем чётности. Выдерживает отказ двух дисков. Минимально 4 диска.
- RAID 10: Комбинация RAID 1 и RAID 0 (зеркало+чередование). Высокая производительность и отказоустойчивость. Минимально 4 диска.

## 3. Создайте из них raid 0 массив
```bash
sudo apt-get install  mdadm # установим прогу для создания raid массивов
sudo mdadm --create /dev/md0 --level=0 --raid-devices=2 /dev/sdc1 /dev/sdd1 
```
- `--create` — ключ создания нового массива
- `/dev/md0` — имя создаваемого RAID-устройства (первый массив).
- `--level=0` — уровень RAID (0 — чередование, stripe).
- `--raid-devices=2` — количество дисков в массиве (2 диска).
- `/dev/sdc1 /dev/sdd1` — разделы, которые будут объединены в RAID.

## 5. Удалите raid0 и создайте raid1
```bash
sudo mdadm --stop /dev/md0 # удаляем наши старания
sudo mdadm --create /dev/md1 --level=1 --raid-devices=2 /dev/sdc1 /dev/sdd1 # новый массив
```

## 6. В чём между ними разница?
RAID 0: данные разбиваются на блоки и пишутся на все диски одновременно. Скорость чтения/записи выше, но при отказе одного диска все данные теряются.
RAID 1: данные полностью дублируются на все диски. Надёжность выше (работает даже при отказе одного диска), но полезный объём равен объёму одного диска.
## 7. Есть ли файловые системы которые поддерживают raid массивы без стороннего ПО
Да, некоторые файловые системы (ZFS, Btrfs) поддерживают RAID-подобные функции на уровне ФС без отдельного RAID-контроллера или `mdadm`
